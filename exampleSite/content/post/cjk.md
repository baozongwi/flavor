主题默认不附带字体文件。未配置 `params.font` 时，正文字体是系统 UI 黑体（苹方 / 微软雅黑 / Noto Sans SC）。

要挂 webfont 时把 css 指到自建或 CDN 的 `result.css` 即可；`http(s)://` 会自动 preconnect。
